### 🚀 Featured Projects

#### 🛒 **Swift Cart — E-Commerce Backend Engine**

- Architected production-grade RESTful APIs using **Node.js, Express.js, PostgreSQL, and Prisma ORM**.
- Secured authentication flows with **JWT, bcrypt, and Helmet middleware**.
- Integrated **Nodemailer** for automated transaction notifications and password resets.

#### 🔔 **Real-Time Notification & Geofencing System**

- Developed a high-throughput notification engine using **MongoDB Change Streams** and **Socket.IO**.
- Integrated **OpenRouteService** with GeoJSON indexing for spatial geofencing.
- Connected API workflows to React frontends via **RTK Query** with Redis query caching.

- Built a multi-tier Role-Based Access Control engine with hierarchical permission scopes.
- Implemented **AES-256-CBC encryption** and database row-level protection with Joi payload validation.
